# Contributing to this record

A contribution is one dated cycle in `ledger/mars.json`, under your own name. The rules, the contribution kinds and
the templates are in the protocol repository: https://github.com/Nervous-Machine/DEBRIEF/blob/main/CONTRIBUTING.md

For this mission the most useful contributions are:

- **A rerun** of any cycle from the public RAD data under its registered rule, reported with the Rerun report issue
  form. Cycles ten to sixteen have not been rerun by anyone; see the README.
- **Data** for 2024 at Mars that bears on an open gap in `ASKS.md`, offered with the Data contribution form.

A plain issue is fine for a question. Nobody edits a contributed cycle file after it is merged; a correction or
withdrawal is a new file.
